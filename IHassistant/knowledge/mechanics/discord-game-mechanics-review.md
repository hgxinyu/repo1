## 孙悟空自伤联动：优先补充的配队风险

来源：Hanchock，2026-07-30 发布，2026-07-31 编辑的 `Selfdamage Bug`。

作者报告：具有自伤机制的英雄释放普攻或主动时，可能把自身纳入“目标”判定，使某些对目标触发的额外效果打到自己。追加自伤会受到自身输出和防御属性影响，例如全增伤、全减伤。作者提到 GSSW（孙悟空）和 LDA/LODA（Lord of Death Azrael），但不能把当时“只有两个英雄”的说法当作永久完整名单。

| 来源 | 作者报告的交互 | 记录边界 |
| --- | --- | --- |
| Elyvia / Fairy’s Guard | 给随机 3 名友方的效果可能在悟空主动时反打自身；均衡配置可能致死，不屈配置可能损失层数 | 社区报告，未复现；不可等同于技能自带的正常扣血 |
| BDSM / Bloom Devouring Star Madeleine | 护盾超过 50% 时的额外伤害层可能参与自伤 | 原帖称单独不一定直接致死，与 LBRM 叠加更需留意 |
| LBRM / Lady of Blossom Realm Melissa | 为攻击最高友方提供的额外伤害层可能参与自伤 | 需核对悟空是否实际获得该效果及叠加来源 |
| 印痕灌注暴击线终点 | 无视防御的追伤可能导致带均衡的悟空自杀 | 与本地利刃分支1左线“累计暴击 2 次，下次主动追加 3000% 攻击”的描述相符，节点对应为对照推断；作者提出第 3 回合前结束战斗的例外，不能作为安全保证 |
| 根源灌注的一个节点 | 可能对悟空自身施加沉默 | 原帖以 `Core_inf_lethargy` 图标指代；中文名称和准确节点未确认，不猜测对应套装 |

作者限定：高额 Buff 叠加后才容易显现，通常提到虚空战役第 10 章以后或星域远征。这里的 VC 是 Void Campaign，不是 glossary 中 `VC+数字` 可能表示的 Void Corruption。不能把此风险推广为所有阶段禁用相关英雄。

后续验证应记录玩法、完整六人阵容、悟空状态与血线、均衡/不屈、灌注节点、获得的追加伤害 Buff、自伤发生回合及不屈层数变化；分别处理 PVE 风险和作者提到的 LDA PVP 用法。

## 免控来源分层与控制命中

来源：Dethroy，2021-02-16；solojen，2021-02-25。

令 `P` 为战前免控之和，`G` 为针对该控制类型的科技免控，`B` 为战中免控之和。社区公式为：

```text
总免控 = 1 - (1 - P) * (1 - G) + B
```

- 原帖把英雄被动、神器、皮肤列为战前来源；头像框、光环、Buff、工坊升级、Debuff 列为战中来源。这是当时的来源分类，新系统须单独确认。
- 本地旧公式 `控制概率 * (1 - 普通免控) * (1 - 科技免控)` 在没有战中来源时与上述思路一致；把战中来源提前并入普通免控则不等价。
- 算术对照：`P=50%、G=20%、B=30%` 时，社区式得 90% 免控；先合并 P+B 再合科技得 84%。这只是公式对比，不是实测结果。
- 原帖算例可出现超过 100% 的免控数值；最终概率上下限、抵消免控率的结算位置，以及新系统来源的分类均待验证。不要输出负的被控概率，也不要自行将此旧式与抵消公式拼接为现行完整公式。

控制命中率（Control Precision）与抵消免控率不同。社区给出：

```text
免控判定前的控制概率 = 基础控制概率 * (1 + 控制命中率)
40% * (1 + 50%) = 60%
```

这里的 60% 尚未计入目标免控，不是最终命中率；也不是把 40% 与 50% 相加。超过 100% 时的处理与免控判定顺序待确认。

## 神圣格挡：技能文字与触发范围的争议

本地保留的技能文字是“使格挡成功后的减伤对所有类型的伤害生效”。这不自动说明所有伤害方式都触发格挡判定。2022-10-22 子帖比较两份均为 100% 格挡的女王资质，作者报告如下：

| 测试伤害来源 | 无神圣格挡 / 有神圣格挡的报告数值 |
| --- | --- |
| Carrie 印记 | 2,619,002 / 2,619,002 |
| Drake 印记 | 371,566 / 371,566；作者指出破防归零格挡是干扰因素 |
| Elyvia Fairy’s Guard，第 2 回合 | 1,596,783 / 1,596,783 |
| Eos Divine Retribution | 22,846,932 / 22,846,932 |
| 女王反击 | 1,749,363 / 1,749,363 |
| Phorcys 回合末伤害 | 3,591,058 / 3,591,058 |
| Amen-Ra 治愈诅咒 | 15,315,326 / 15,315,326 |
| Saja 持续伤害 | 477,471 / 477,471 |

SFX 反击测试也未显示明确收益；其中一次数值不同，作者归因为刺客星灵等级变化。上述测试存在年代、配置和未复核录像的限制，不能推出“神圣格挡完全无效”，也不能据此给出全英雄白名单/黑名单。

采用口径：区分伤害类型与伤害方式；对被动、印记、持续伤害、反击，不默认额外获得神圣格挡减伤。需要该词条改变配装结论时，先验证具体技能是否能触发判定。

## 觉醒攻血资质的属性换算

来源：Azu / Azulol，2022-08-27。

```text
觉醒攻击或生命倍率 = 1 + 对应资质数值 / 10000
攻击资质 2975 -> 1.2975 倍（增加 29.75%）
```

原帖称其作用于租客加成前的攻击/生命，包含固定属性与树的固定属性；速度资质直接增加相应速度。例：租客加成前 1,000,000 攻击，经 2975 攻击资质换算为 1,297,500。

这是历史属性计算资料，不是魂力总值/均值公式，也不是租客加成后整体再乘一次的依据。当前列车、飞升等新增来源的结算位置未在该帖说明，仍需验证。

## 基础规则补清与一致项

来源：Whiskey Alpha Kilo Alpha，2019-09-18 起的属性说明及 2020 年补充。

- 同速顺序、初始 50 能量、普攻 +50、受击 +10/受暴击 +20、溢出能量转技能伤害率，与本地记录基本一致；特殊技能另行处理。
- 护甲公式分母 `等级*20+180` 与本地 `200+20*(等级-1)` 代数等价。旧帖另称护甲减伤上限 90%，当前版本未复现，保留为补充线索。
- 精准每 1% 对应 0.3% 增伤、150% 精准达到 45% 上限，及暴伤 `1.5+2*暴伤率`，与本地记录方向一致，不能凭旧帖取消现有版本待确认项。
- 格挡减伤为乘 0.7；暴击同时被格挡时再乘 0.8，合计保留 56% 伤害，而非直接减去 50%。
- 持续伤害的技能伤害率增益，旧帖给出完整倍率 `1+SD/(持续回合数+1)`。原本只有 `SD/(持续回合数+1)` 的表达应明确为增量；不同技能与现代伤害类型的适用性仍需验证。
- 闪避抵消为减法，旧帖称闪避作用于普攻/主动，不作用于被动及印记伤害，并受 Drake 破防影响。记录为具体交互线索，不扩展到所有新增技能。

## 净化与技能特效分类

来源：Mapi，2022-01-10；sorbitol，2021-09-25。

- 控制净化：帖子列举变形、冰冻、眩晕、缠绕、嘲讽、光封、恐惧、石化。名单未列沉默、目眩，不据此推断其无法净化。
- 印记净化：列举 Aida 的 Balance、Carrie 的 Devour、Phorcys 的 Decay、Amen-Ra 的 Curse、Drake 的 Black Hole、Gloria 的 Bubble，以及 Asmodel/Rosa 的暴击印记。这里的 Balance 是印记，不是均衡赋能。
- 持续伤害净化：流血、燃烧、中毒。
- 属性降低净化：攻击、暴击、暴伤、速度、减伤、护甲、格挡、精准、治疗效果、造成全伤害等减益。
- 不可净化的独有技能效果：旧帖列举 Drake 的 Defence Down、Eloise 的 Scarred Soul、Tix 的 Wraith、Ithaqua 的 Ghost、Gustin 的 Link、Phorcys 的 Corruption、Elyvia 的 Shrink 等。不能仅凭名字像“印记”就归入印记净化，也不把此旧名单当完整清单。
- 能量增加可被视为属性增益；2021 年帖子以 Carrie 普攻先给能量再扣能量、可能触发 Phorcys 效果为例。此英雄交互尚未本地复现。

## 保留冲突，不直接替换的公式

### 普通 ADD 与极境鹿角

solojen 的 2021-02-14 帖子把当时女王、闪烁鹿角和 Flora 减益相加：`1+(0.15+0.03*2-0.1)=1.11`。这可用于说明当时同一 ADD 池的加减关系。

本地 Boss 公式使用极境鹿角，并将其单列乘区。旧闪烁鹿角与极境鹿角不能直接视为同一机制；本次保留本地公式，同时标记需要当前版本对照测试。更不能把普通 ADD 池与巨人杀手、神能压制、超过 15 回合的系统增伤混为一个池。

### 真实伤害与回合增伤

2020 年旧帖对按伤害量追加的伤害使用“忽略所有乘区”等说法，且作者带有不确定措辞；后续同频道又讨论回合增伤重复作用于反伤。不能用旧帖的 TRUE DAMAGE 名称覆盖本地 2026 年传统/真实/惩戒三类及具体技能拆段规则。

旧帖给出第 16 回合起 `1.15^(回合数-15)`、回合上限 127，并指出部分特殊伤害不受影响。本地已有同方向的待确认记录。本次只补历史来源，不宣称所有玩法均有该上限或系数。

### 原帖算术疑点

- 2021-01-05 生命公式示例写 `floor(1,064,817*(1.12*5))=1,810,188`，左右不等。不得把该表达照抄进属性计算器，也不猜测缺失项后宣称已修正机制。
- 2020 年反伤示例先设受到 1000 伤害反弹 700，随后第 25 回合写 `4045*4.045=16362`，疑似遗漏原来的 70% 反伤系数。其机制方向与算例正确性应分开处理。
