# 基金材料性价比

来源：用户提供截图 `Weixin Image_20260704213500_128_58.jpg`。

## 计算口径

```text
比例 = 基金12倍 / 任务每10材料换取量
```

倍数越高代表基金越实惠。

新版攻略图输出：`flipgame/images/fund-material-value-guide.png`，由 `scripts/generate-fund-material-value-guide.py` 生成。
