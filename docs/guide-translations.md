## 图稿规则

- 面向中文玩家的成图优先使用本文件中的中文术语，不在标题、卡片或提醒中混用英文缩写。
- 活动结束前补投入用“最后一天”或“最后”，不用“末日”。图中不放“公告已核对”等制作过程说明，来源核对情况保留在笔记。
- 只有在中文译名尚未确认时才临时保留英文，并明确标记“待确认”。
- 攻略图可以恢复简短的来源行，统一写作 `Reference · <来源>`；不要在图中放冗长原始链接或频道编号。
- 底部品牌统一写作 `ShineGame.Pro  ·  Idle Heroes Guide`。底注和紧凑说明中的并列分隔优先使用中间点 `·`，不要使用逗号串联。
- 中英文自制攻略图都使用正文中段的淡色斜向 `ShineGame.Pro` 水印；页眉和二维码区域不覆盖。外部收集原图及其直接翻译版本不加水印。
- 中文攻略图使用上面的接力换算档位；英文攻略图保留来源中的美元档位（`$15` / `$50` / `$130` / `$200+`），方便英文用户直接对照游戏内付费路线。
