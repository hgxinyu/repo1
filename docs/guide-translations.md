# 攻略翻译与术语

本文件记录攻略图、活动分析和相关页面中可重复使用的中文译名。用户明确确认的译名优先于临时直译；新增术语时保留英文原词，避免后续活动中出现多种中文写法。

## 每周活动术语

| 英文 | 中文 | 使用说明 |
|---|---|---|
| `Erskor` | 厄斯特尔 | 英雄名称。 |
| `Nest Purge` | 清巢行动 | 活动名称。 |
| `War Cache` | 战备密保 | 活动名称；使用用户确认的写法。 |
| `CSG` | 绑钻 | 攻略图中不再保留英文缩写。 |
| `RNG` | 随机性 | 根据句子可写为“随机机制”“随机收益”等自然中文。 |
| `F2P` | 免费玩家 | 面向用户的图文使用中文。 |
| `Mini Gala` | 小觉醒活动 | 活动简称。 |
| `Life Star` | 星魂 | 星魂系统或星魂养成；不要直译为“生命之星”。 |
| `Relay` | 接力 | 礼包/付费路线名称。资料中若出现 `Replay`，也按“接力”处理。 |

## 接力价格换算

攻略图不显示美元总价，也不展开此前购买的全部礼包价格。统一只写接力路线的最高礼包档位，格式为“接力到 N”。

| 英文分析中的档位 | 攻略图写法 |
|---|---|
| `$15 Relay` | 接力到 `68` |
| `$50 Relay` | 接力到 `148` |
| `$130 Relay` | 接力到 `328` |
| `$200+ Relay` | 接力至 `498` 及以上 |

## 图稿规则

- 面向中文玩家的成图优先使用本文件中的中文术语，不在标题、卡片或提醒中混用英文缩写。
- 只有在中文译名尚未确认时才临时保留英文，并明确标记“待确认”。
- 攻略图可以恢复简短的来源行，统一写作 `Reference · <来源>`；不要在图中放冗长原始链接或频道编号。
- 底部品牌统一写作 `ShineGame.Pro  ·  Idle Heroes Guide`。底注和紧凑说明中的并列分隔优先使用中间点 `·`，不要使用逗号串联。
- 中英文自制攻略图都使用正文中段的淡色斜向 `ShineGame.Pro` 水印；页眉和二维码区域不覆盖。外部收集原图及其直接翻译版本不加水印。
- 中文攻略图使用上面的接力换算档位；英文攻略图保留来源中的美元档位（`$15` / `$50` / `$130` / `$200+`），方便英文用户直接对照游戏内付费路线。
